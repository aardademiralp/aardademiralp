# Selam, ben Arda 👋

İstinye Üniversitesi **Bilişim Güvenliği Teknolojisi** programında 2. sınıf öğrencisiyim. Özellikle siber güvenlik, ağ güvenliği ve yazılım geliştirme alanlarıyla ilgileniyorum.

Bunun yanında aktif olarak **oyun geliştirme** üzerine çalışıyor ve farklı yazılım projeleri geliştiriyorum. Öğrenirken gerçek projeler ortaya çıkarmaya ve farklı teknolojiler üzerinde kendimi geliştirmeye odaklanıyorum.

* **Oyun Geliştirme:** Unity

* **Araçlar:** Git, GitHub, VirtualBox
* **İlgi Alanları:** Ağ Güvenliği, Sızma Testleri, Ağ Analizi, SSL/TLS, Otomasyon, Oyun Geliştirme
